# Reference review

Inspected on 2026-10-31: [ameynarwadkar/Tennis-Analysis-System](https://github.com/ameynarwadkar/Tennis-Analysis-System), commit [`25b3e92ace9c93f69eb90d3dcee129e7b49da644`](https://github.com/ameynarwadkar/Tennis-Analysis-System/tree/25b3e92ace9c93f69eb90d3dcee129e7b49da644). This is a source inspection, not a claim that its end-to-end script was executed or benchmarked. Baseline Lab does not import or copy its implementation.

The reference makes the detection → court display → annotated video sequence understandable. Its script assumptions are useful review topics; they are not a reusable API contract.

## Licensing and reuse boundary

The reference repository's [LICENSE](https://github.com/ameynarwadkar/Tennis-Analysis-System/blob/25b3e92ace9c93f69eb90d3dcee129e7b49da644/LICENSE) is Apache-2.0. Copying code would require preserving that license and relevant notices and marking modifications. No reference implementation source is copied here.

Its [requirements](https://github.com/ameynarwadkar/Tennis-Analysis-System/blob/25b3e92ace9c93f69eb90d3dcee129e7b49da644/requirements.txt) include Ultralytics, Torch, and CUDA-specific pins. A repository code license does not resolve the separate terms for model weights, their training data, broadcast footage, or dependency binaries. The reviewed README and license do not establish a separate rights-cleared grant for `input_videos/input_video1.mp4`; it must not be used as Baseline Lab's public example merely because it is downloadable. Public sample provenance belongs in the sample's own attribution record.
